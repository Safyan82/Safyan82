## 🚀 Side projects — shipping in public

### 📸 SnapStack — *your screenshots, finally searchable*
Privacy-first Android screenshot organiser with **fully on-device AI search**. No cloud, no uploads.
- Hybrid search: **exact (SQLite FTS5) + semantic (`all-MiniLM-L6-v2` via ONNX) + fuzzy**, merged with **Reciprocal Rank Fusion**
- OCR + AI categorisation, SHA-256 dedup, foreground service that catches every new screenshot

`React Native` `Expo` `ONNX Runtime` `SQLite FTS5` `Kotlin service`

### 🧾 VatScan — *snap a receipt, get HMRC-ready VAT*
Receipt-to-VAT app for UK freelancers → [vatscan.app](https://vatscan.app)
- ML Kit on-device validation → Google Vision OCR → GPT-4o-mini extraction on Supabase edge functions
- VAT claimability classification, duplicate detection, device-fingerprint abuse prevention, Stripe billing

`React Native` `Supabase` `OpenAI` `ML Kit` `Stripe`

### 💾 StorySaver — *save stories from anywhere*
Cross-platform saver for Instagram, TikTok, Pinterest, Facebook and WhatsApp statuses.
- Native share extensions + an embedded WhatsApp Web session with injected JS for iOS
- Remote OTA config for DOM selectors, so it survives UI changes without an app update

`React Native` `Zustand` `MMKV` `RevenueCat`
